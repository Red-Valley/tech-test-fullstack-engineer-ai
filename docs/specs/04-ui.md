# Specs for "UI"

**Branch:** `feature/ui`

---

## Summary

The catalog management and AI chat capabilities need a unified web interface. This feature delivers a Next.js (React + App Router) application that presents game data as a table or card grid and embeds the AI chat alongside it, styled end-to-end with Tailwind CSS.

## Requirements

### Requirement 1 — UI

**Acceptance Criteria:**
- [ ] AC-1.1: Dashboard view (table or cards) + chat view.
- [ ] AC-1.2: Tailwind is fine.
- [ ] AC-1.3: Frontend framework: Next.js (React + App Router).
